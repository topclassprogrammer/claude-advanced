# PRD: Загрузка файла встречи для хранения и отображения

**Дата**: 2026-08-18
**Статус**: Draft

# Цель
Любой авторизованный пользователь может прикрепить к встрече файл (запись, документ, презентацию и т.п.), чтобы он хранился вместе со встречей и был доступен для просмотра/скачивания при открытии страницы этой встречи.

## Пользовательские сценарии
- Авторизованный пользователь открывает страницу встречи -> видит блок загрузки файла.
- Пользователь выбирает файл и загружает его -> файл сохраняется и привязывается к встрече, в блоке появляется его карточка (имя, размер, дата загрузки).
- Авторизованный пользователь открывает страницу встречи, к которой уже прикреплён файл -> видит карточку файла со ссылкой на скачивание/просмотр.
- Неавторизованный пользователь пытается открыть блок загрузки/файл встречи -> получает отказ в доступе (401).

## В скоупе
- Загрузка файлов на встречу (без ограничения по типу материала — запись, документ, презентация и т.п.).
- Хранение файла на локальной файловой системе сервера `apps/api`.
- Привязка файла к встрече в БД (метаданные: имя, размер, MIME-тип, дата загрузки, путь к файлу).
- Эндпоинт загрузки файла для встречи (доступен любому авторизованному пользователю системы, независимо от того, организатор он или нет).
- Эндпоинт получения/скачивания файла встречи (доступен любому авторизованному пользователю системы).
- Отображение прикреплённого файла на странице встречи в `apps/web`: имя файла, размер, дата загрузки, ссылка на скачивание/просмотр.
- Форма/элемент загрузки файла на странице встречи, если файл ещё не прикреплён.
- Кнопка загрузки с drag-and-drop зоной и прогресс-баром.
- Иконка типа файла по MIME-type
- Ограничение максимального размера загружаемого файла.
- Валидация: отказ в загрузке при превышении лимита размера.

## Не в скоупе
- Любая обработка содержимого файла (транскрибация, распознавание речи, извлечение текста, генерация саммари и т.п.) — задел на будущую итерацию.
- Предпросмотр содержимого файла (видео/аудио плеер, просмотр документа) — только скачивание/базовая ссылка.
- Поддержка загрузки нескольких файлов одновременно одним запросом.
- Версионирование файлов (история предыдущих загрузок при замене).

## Технические ограничения
- Monorepo: NestJS backend, Next.js frontend, CQRS через CommandBus/QueryBus.
- Prisma + PostgreSQL: схема расширяется добавлением модели MeetingFile; миграция обязательна.
- Максимальный размер файла: 100Мб
- Допустимые типы: видео (mp4, mov, webm), аудио (mp3, m4a, wav), документы (pdf, docx, xlsx, pptx, txt)
- Файлы хранятся на локальном диске сервера `apps/api`
- Авторизация: только владелец встречи может удалять файлы; просмотр и скачивание - для всех участников

## Критерии готовности
- [ ] Любой авторизованный пользователь может загрузить файл на встречу через UI страницы встречи, независимо от того, является ли он организатором этой встречи.
- [ ] Загруженный файл сохраняется на диске сервера, метаданные — в БД, связаны с конкретной встречей.
- [ ] На странице встречи с прикреплённым файлом отображаются имя файла, размер и дата загрузки.
- [ ] На странице встречи с прикреплённым файлом доступна ссылка/кнопка для скачивания файла.
- [ ] Повторная загрузка файла на встречу (любым авторизованным пользователем) заменяет ранее прикреплённый файл (старый файл удаляется с диска).
- [ ] Загрузка файла, превышающего лимит размера, отклоняется с понятной ошибкой, файл не сохраняется.
- [ ] Любой авторизованный пользователь может скачать файл с любой встречи.
- [ ] Неавторизованный запрос к эндпоинтам загрузки/скачивания отклоняется (401).
- [ ] E2E-тесты покрывают сценарий: загрузка -> отображение -> скачивание -> удаление
