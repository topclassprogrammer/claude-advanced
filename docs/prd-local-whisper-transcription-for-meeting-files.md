# PRD: Транскрибация аудио/видео файлов встречи через локальный Whisper

**Дата**: 2026-08-23
**Статус**: Draft

## Цель

После загрузки к встрече файла в формате mp4 или mp3 система должна автоматически распознать речь через локально запущенную модель Whisper (уровень "low") и показать пользователю статус и результат транскрибации — чтобы не нужно было пересматривать/переслушивать запись целиком для поиска нужной информации.

## Пользовательские сценарии

- Пользователь загружает mp4/mp3 файл к встрече -> транскрибация запускается автоматически, без дополнительных действий пользователя.
- Пользователь открывает страницу встречи, пока транскрибация ещё выполняется -> видит статус "в процессе" рядом с файлом.
- Пользователь открывает страницу встречи после завершения транскрибации -> видит статус "готово" и текст транскрипта.
- Транскрибация завершается ошибкой (повреждённый файл, сбой модели и т.п.) -> пользователь видит статус "ошибка" вместо текста.
- Пользователь удаляет файл встречи, транскрибация которого ещё не завершена или уже завершена -> транскрипт удаляется вместе с файлом.
- Пользователь загружает файл в формате, отличном от mp4/mp3 (например, pdf, docx — уже поддерживаемые типы файлов встречи) -> транскрибация не запускается, статус транскрибации для такого файла не отображается.

## В скоупе

- Автоматический запуск транскрибации сразу после успешной загрузки файла встречи с MIME-типом mp4 или mp3.
- Локальный запуск Whisper (модель "low") без обращения к внешним API.
- Хранение статуса транскрибации файла: в процессе / готово / ошибка.
- Хранение и отображение текста транскрипта после успешного завершения.
- Отображение статуса транскрибации рядом с файлом на странице встречи для организатора этой встречи (тот же круг доступа, что и у остальных операций с файлами встречи).
- Отображение текста транскрипта на странице встречи после завершения.
- Удаление транскрипта при удалении соответствующего файла встречи.
- Актуализация статуса на странице встречи без ручной перезагрузки страницы пользователем.

## Не в скоупе

- Транскрибация файлов в форматах, отличных от mp4/mp3.
- Выбор пользователем модели Whisper или языка распознавания — используется одна зафиксированная конфигурация (модель "low").
- Ручной повторный запуск/отмена транскрибации пользователем.
- Редактирование текста транскрипта пользователем.
- Поиск по тексту транскрипта, экспорт транскрипта в файл.
- Диаризация (разделение по говорящим), таймкоды/субтитры, синхронизация текста с видео/аудио плеером.
- Транскрибация уже существующих (загруженных до появления этой фичи) файлов встреч.
- Уведомления (email/push) о завершении транскрибации.

## Технические ограничения

- Транскрибация выполняется локально на сервере — длительность обработки зависит от длины файла и ресурсов сервера, результат недоступен мгновенно.
- Whisper поддерживает только файлы в пределах текущих ограничений загрузки файлов встречи (`MAX_FILE_SIZE_BYTES`, до 10 файлов на встречу).
- Одновременная обработка нескольких файлов на локальной модели ограничена ресурсами сервера (CPU/GPU) — возможна очередь обработки.

## Критерии готовности

- [ ] После загрузки mp4/mp3 файла к встрече транскрибация запускается автоматически, без действий пользователя.
- [ ] На странице встречи рядом с файлом отображается статус транскрибации: "в процессе", "готово" или "ошибка".
- [ ] После завершения транскрибации на странице встречи отображается текст транскрипта.
- [ ] Статус на странице встречи обновляется до "готово"/"ошибка" без ручной перезагрузки страницы пользователем.
- [ ] Транскрипт и его статус доступны только организатору встречи, как и остальные данные о файлах встречи.
- [ ] При удалении файла встречи связанный с ним транскрипт (текст и статус) удаляется.
- [ ] Для файлов в форматах, отличных от mp4/mp3, статус транскрибации не отображается и транскрибация не запускается.
- [ ] Сбой транскрибации (например, повреждённый файл) отражается статусом "ошибка", не блокируя остальной функционал страницы встречи.
